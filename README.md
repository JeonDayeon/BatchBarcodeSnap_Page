# BatchBarcode Snap — 웹 버전

정적 웹앱/PWA입니다. 사진과 문서는 현재 브라우저의 IndexedDB에 보관하며 자동으로 서버에 업로드하지 않습니다.

현재 릴리스: **2026-10-29-web18**

- 홈의 **사진에서 바코드 인식**에서 여러 사진을 선택하고 원본/인식 결과를 확인합니다.
- 카메라 촬영, 사진별 확대·회전·재인식, 문서 저장·검색·휴지통 기능을 제공합니다.
- XLSX는 고유 바코드·사진별 기록·바코드별 기록 3개 시트와 사진 미리보기를 포함합니다.
- 문서 공유는 파일 준비 후 **파일 공유**를 누릅니다. 브라우저가 거절하면 같은 창의 **파일 저장**을 사용합니다.
- 사용 안내는 [help.html](help.html)에서 확인하거나 해당 링크를 공유할 수 있습니다.

## 사진 인식

사진 인식은 로컬에 포함된 **zxing-wasm 3.1.6 / zxing-cpp WebAssembly**를 사용합니다. 전체 사진 다중 인식, 원본에서 직접 자르는 중첩 상세 영역, 긴 Code 128을 보존하는 행/열 보완 인식을 수행합니다. 회전·반전 탐색을 사용하고, 오류로 판정된 결과는 저장하지 않습니다. 동일 문자열이라도 다른 위치에 있는 바코드는 사진별 결과에 유지하며, 문서 고유 목록에서는 한 번만 표시합니다.

모듈 Worker를 지원하면 사진 인식을 별도 스레드에서 실행합니다. 대체 경로는 메인 스레드에서 같은 알고리즘을 실행합니다. 원본 파일은 자동 업로드하거나 축소해서 덮어쓰지 않습니다. 전체 개요 및 큰 크롭의 처리 해상도에는 메모리 제한을 두고, 상세 영역은 원본에서 다시 읽습니다.

실시간 카메라 미리보기도 별도 Worker에서 zxing-cpp로 한 프레임의 여러 바코드를 읽습니다. 전체 프레임과 중앙 상세 영역을 최대1920px에서 읽고, 지원 브라우저의 기본 BarcodeDetector를 보조로 사용합니다. 사진 인식에서도 기본 디코더를 사용 가능한 경우 함께 실행합니다. 첫 읽음은 주황 표시, 두 번 확인하면 초록 체크를 표시하고, 촬영 사진의 저장 목록과 현재 화면의 읽음 수를 구분합니다. 기본 엔진 실패 시 기존 ZXing-JS가 보조 경로로 동작하며, 보조 경로 최초 로드에는 인터넷 연결이 필요합니다. Android ML Kit 및 ARCore 공간 추적을 웹에서 실행하는 구조는 아닙니다.

## 촬영과 완료 표시

지원 카메라에서는 ImageCapture.takePhoto로 실제 사진을 촬영하며 요청 해상도는 약12MP 이하로 제한합니다. 지원하지 않거나 실패하면 기존 영상 프레임 촬영을 사용합니다. 회전은 사진에만 적용합니다. 처리 중인 사진 결과를 미리 열어0개로 고정되는 경로를 막고, 사진 완료/읽음없음/오류/값충돌을 구분합니다. 카메라의 현재 확인 수와 촬영 사진의 저장 목록도 구분합니다.

## 검증 범위

이 PC에서 제공된 원본 라벨 사진 2장을 오프라인으로 처리해 각각 Data Matrix 3개와 Code 128 15개, 총 18개 위치를 읽었습니다. 90°·180° 회전 후에도 값과 개수가 동일했습니다. 작은 빈 이미지, 별도 위치의 동일 값 보존, 겹친 결과 병합을 포함한 35개 검사를 통과했습니다. 다른 포장 라벨 사진4장에서는 일부 또는 전체Code128을 읽지 못했습니다. 확대·회전·대비보정 및 별도 디코더 비교로도 해결되지 않은 경우가 남아 있습니다. 1920px의 가상 카메라 프레임 시험은 MPS사진1이17/18개, 사진2가18/18개였으며0도/90도에서 동일했습니다. 이것은 실제 영상이나 휴대폰 처리 속도 검증이 아닙니다. 기본 BarcodeDetector와ImageCapture실물 기기 시험은 미완료이며 모의 API 동작만 확인했습니다.

브라우저에서는 320px 화면에서 원본/결과 사진 표시, 빈 결과 글줄, 촬영·사진 불러오기 SVG 아이콘 정렬, 공유 거절 후 저장 안내, 기존 사진 재인식 실행을 확인했습니다. 새 사진 선택부터 저장까지 브라우저 전체 경로는 미검증입니다. 실제 Android/iPhone 촬영과 시스템 공유 완료는 기기에서 확인해야 합니다.

## 사용·배포

카메라는 HTTPS에서 권한을 허용해야 사용할 수 있습니다. iPhone은 Safari의 공유 메뉴에서 홈 화면에 추가할 수 있습니다. 손전등·진동·파일 공유는 기기와 브라우저별로 지원이 다릅니다. 브라우저 데이터를 지우면 기록이 없어질 수 있으니 중요한 문서는 파일로 내보내 보관하세요.

로컬에서는 프로젝트 루트에서 `node web-scanner/serve-local.mjs`를 실행하고 `http://localhost:8080/`을 엽니다. GitHub Pages에서는 이 폴더의 실행 파일을 저장소 루트에 배포하고 기존 Pages 워크플로를 사용합니다. `checks/`, `publish-worktree/`, 테스트 이미지, 압축파일은 게시하지 않습니다. 인식 엔진의 제3자 라이선스는 `vendor/zxing-wasm/`에 있습니다.
