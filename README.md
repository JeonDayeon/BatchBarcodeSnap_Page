# BatchBarcode Snap — 웹 버전

Android 앱의 주요 흐름을 웹으로 옮긴 정적 PWA입니다. 홈에서 스캔을 시작하거나 저장된 문서를 열고, 한 문서에 사진을 계속 추가한 뒤 사진별 결과와 문서 고유 바코드 목록을 확인할 수 있습니다. 카메라 화면과 ZXing-JS 인식기는 기존 웹 스캐너를 유지했습니다.

## GitHub Pages에 올리기

1. GitHub에서 저장소를 만들고 이 `web-scanner` 폴더 **안의 파일과 폴더**를 저장소 루트에 업로드합니다. `index.html`, `app.js`, `styles.css`, `manifest.webmanifest`, `sw.js`가 루트에 보여야 합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. 배포 소스를 **Deploy from a branch**로 선택하고 업로드한 브랜치와 `/(root)`를 선택해 저장합니다.
4. GitHub가 표시하는 `https://<계정>.github.io/<저장소>/` 주소를 휴대폰에서 엽니다. 카메라 사용은 HTTPS 페이지에서 허용해야 합니다.
5. Android Chrome은 메뉴에서 **앱 설치/홈 화면에 추가**, iPhone Safari는 **공유 → 홈 화면에 추가**를 선택하면 앱처럼 실행할 수 있습니다.

GitHub Pages는 정적 호스팅만 제공합니다. 이 웹앱은 서버나 계정에 데이터를 전송하지 않습니다. 사진과 문서는 각 브라우저의 IndexedDB에 저장되므로 Android와 iPhone 사이에 자동 공유되지 않습니다. 브라우저 데이터 삭제로 로컬 기록이 지워질 수 있으니 XLSX/CSV 내보내기로 백업하세요.

## 로컬 실행

프로젝트 루트에서 `node web-scanner/serve-local.mjs`를 실행한 뒤 같은 PC에서 `http://localhost:8080/`을 엽니다. 카메라는 HTTPS 또는 localhost에서만 브라우저 권한을 받을 수 있습니다. ZXing-JS 모듈은 esm.sh에서 가져오므로 최초 로드와 인식에 인터넷 연결이 필요합니다.

Android 휴대폰을 USB로 연결해 로컬 테스트하려면 USB 디버깅을 켜고 다음을 실행한 뒤 Chrome에서 `http://localhost:8080`을 여세요.

## 앱 흐름과 기능

- 홈: 새 바코드 스캔 또는 저장 목록 열기.
- 스캔: Android와 같은 순서로 상단 제어, 카메라 미리보기, 회전 버튼, 작업 요약, 마지막 결과, 촬영/가져오기, 현재 인식 목록/저장 버튼을 배치합니다. 웹 카메라를 사용할 수 없으면 미리보기 중앙의 시작 버튼과 갤러리 가져오기를 사용할 수 있습니다.
- 회전: 회전 버튼을 누르면 이후 촬영 사진만 시계 방향 90° 회전합니다. 화면 방향은 바뀌지 않습니다.
- 저장 목록: 검색, 저장순 정렬, 선택 내보내기, 휴지통 이동 및 복구.
- 현재 인식 바코드 목록: 문서 고유 문자열을 3개씩 오른쪽 열부터 표시하고, 항목을 누르면 해당 사진 결과로 이동합니다.
- 문서 저장: 파일명, XLSX/CSV 선택, 브라우저 로컬 저장 안내를 제공합니다.
- 문서 상세: 사진별 인식 결과, 문서 내 고유 바코드 목록, 사진 추가, 이름 변경, 3개 시트(`사진별 기록`, `고유 바코드`, `바코드별 기록`)의 XLSX 내보내기. 원본 사진은 XLSX에 삽입하지 않습니다.
- 사진 결과: 원본 사진에 인식 위치를 겹쳐 표시하고 각 사진에서 검출한 문자열을 보여줍니다.
- 한 문서 안에서는 같은 형식과 문자열을 고유 목록에 한 번만 표시합니다. 사진별 위치 검출 기록은 따로 보존합니다.

## 스캐너 및 제한 사항

스캐너는 ZXing-JS를 사용하며 Data Matrix, Code 128 및 여러 일반 포맷을 찾습니다. 실시간/사진 인식은 전체 이미지와 겹치는 3×3 영역을 각각 디코딩한 뒤 문자열·형식·좌표가 가까운 결과를 합칩니다. 이는 한 번에 한 영역에서 하나씩 읽는 방식입니다. 이 구현의 인식률은 Android 앱과 같다고 검증되지 않았으며, 실제 기기와 샘플 사진으로 확인해야 합니다.

브라우저 버전은 화면 이미지 좌표에서 바코드 상자를 따라갑니다. Android 앱의 ARCore 공간 추적 기능은 GitHub Pages 웹 버전에 포함되지 않습니다. 카메라 손전등 제어도 기기/브라우저별 지원이 다릅니다. XLSX 내보내기 라이브러리는 esm.sh에서 받아오므로 인터넷 연결이 필요합니다.

이 저장소는 정적 파일이므로 별도 빌드 과정은 없습니다. 코드 수정 뒤 GitHub Pages에 다시 업로드하면 됩니다. 이 폴더에는 비밀키나 사용자 사진을 올리지 마세요.
