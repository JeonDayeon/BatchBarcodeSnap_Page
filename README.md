# BatchBarcode Snap — 웹 버전

정적 웹앱/PWA입니다. 사진과 문서는 사용하는 브라우저의 IndexedDB에 보관하며 자동으로 서버에 업로드하지 않습니다.

- 촬영/사진 가져오기, 문서별 사진 관리, 바코드 결과와 위치 확인
- 사진 확대·90° 회전·다시 인식, 사진 선택·삭제
- 문서 검색·기간 검색·정렬·선택·휴지통 복구
- 고유 바코드/사진별 기록/바코드별 기록의 3개 XLSX 시트와 사진 미리보기
- 실제 XLSX/CSV 파일 다운로드와 지원되는 브라우저의 파일 공유

현재 릴리스: **2026-10-29-web16**. 저장 목록의 과도한 행 간격, 보이지 않던 휴지통 버튼, 홈 안내문 줄바꿈을 수정했습니다.

카메라는 HTTPS에서 권한을 허용해야 사용할 수 있습니다. iPhone은 Safari의 공유 메뉴에서 홈 화면에 추가할 수 있습니다. 손전등·진동·시스템 공유는 기기와 브라우저별 지원이 다릅니다. 웹에서는 Android ARCore 공간 추적 및 Android용 인식 엔진 비교를 제공하지 않습니다.

인식기는 ZXing-JS이며 최초 로드에 네트워크가 필요합니다. Android 앱과 같은 인식률이라고 검증된 것은 아닙니다. 중요한 기록은 파일로 내보내 보관하세요. 브라우저 데이터를 지우면 기록이 없어질 수 있습니다.

GitHub Pages 배포는 기존 `.github/workflows` 설정을 사용합니다. 배포 버전은 `version.json`에서 확인할 수 있습니다.
