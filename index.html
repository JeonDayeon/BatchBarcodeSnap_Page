저장

웹 기록은 현재 브라우저의 로컬 저장소에 보관됩니다. 브라우저 데이터를 지우면 기록도 삭제될 수 있으니 XLSX/CSV로 백업하세요.

브라우저판은 화면 좌표 추적을 제공하며, Android 앱의 ARCore 공간 고정 추적은 지원하지 않습니다.

실험

사진과 실시간 인식은 zxing-cpp WebAssembly를 사용합니다. 기존 ZXing-JS는 실시간 보조 경로로 유지합니다. Android의 ML Kit 엔진은 웹에서 실행되지 않습니다.

기타

웹 버전 1.3.0 · 촬영·실시간 인식 v18
