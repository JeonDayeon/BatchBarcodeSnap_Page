1

이미 찍어 둔 사진이 있을 때

사진을 불러오세요

홈에서 사진에서 바코드 인식을 누르고, 휴대폰 사진첩에서 라벨 사진을 선택하세요. 여러 장을 한꺼번에 선택해도 됩니다.

사진에서 바코드 인식홈에서 이 버튼을 찾으세요

선택한 사진은 한 작업에 모입니다. 인식이 끝나면 사진 인식 결과 화면으로 자동 이동합니다. 여러 장을 골랐다면 결과 화면의 이전·다음 버튼으로 사진별 결과를 확인하세요.

2

지금 새로 찍을 때만

카메라로 촬영할 수도 있어요

홈의 바코드 촬영 및 스캔을 누르세요. 카메라 권한을 묻는 창이 나오면 허용하고, 라벨에 초점을 맞춘 뒤 아래의 둥근 촬영 버튼을 누르세요.

사진 수사진 불러오기

촬영이 끝나면 아래의 현재 인식 바코드 목록이나 마지막 촬영 · … · 결과 보기를 눌러 원본 사진과 인식 결과를 확인하세요.

사진은 기기에 먼저 저장하고 차례로 인식하므로 인식 중에도 다음 사진을 찍을 수 있어요. 인식 중인 사진은 완료되면 결과 화면이 갱신됩니다.

카메라의 주황 표시는 확인 중이며, 같은 바코드를 두 번 읽으면 초록 체크로 바뀝니다. 아래의 사진 기록 수는 촬영한 사진에서 읽은 수라서 카메라 표시와 다를 수 있습니다.

촬영 화면의 사진 불러오기로 사진첩을 열 수도 있어요. 카메라를 사용할 수 없는 기기에서는 사진 불러오기를 이용하세요.

3

저장하기 전에 꼭 확인

사진 속 위치와 읽은 값을 확인하세요

사진 인식 결과에서 사진에 표시된 바코드 위치와 아래의 읽은 값을 비교하세요. 사진이나 결과 항목을 누르면 크게 볼 수 있습니다.

1 ✓
1 · 읽음사진의 값과 비교하세요
사진의 읽음 개수
그 사진에서 값을 읽은 바코드 위치 수
문서 고유 바코드
여러 사진에서 같은 데이터는 한 번만 센 수

결과는 읽음, 충돌 · 확인 필요, 읽지 못한 후보로 나눠 표시합니다. 주황 후보는 값을 읽지 못했거나 서로 다른 값이 나온 곳이며 실제 바코드가 아닐 수도 있어요. 두 개수가 달라도 오류라는 뜻은 아닙니다. 같은 바코드 데이터가 여러 곳에 반복될 수 있어요.

4

사진이 눕거나 코드가 빠졌을 때

방향을 맞추고 다시 확인하세요

  • 사진 90° 회전사진 방향과 표시 위치를 함께 돌립니다.
  • 다시 인식같은 사진을 다시 분석합니다.
  • 카메라로 돌아가기같은 작업에 새 사진을 더 찍을 수 있습니다.
다시 찍으면 도움이 되는 경우

글자가 흐리거나 빛이 반사될 때는 라벨에 조금 더 가까이 가서 정면으로 찍어 주세요. 바코드 양끝과 주변 여백이 잘리지 않게 해 주세요.

5

나중에 다시 보려면

이름을 정해서 작업을 저장하세요

결과 화면에서 작업 저장 또는 촬영 화면에서 저장을 누르세요. 알아보기 쉬운 파일명을 입력하고 저장 형식을 선택한 뒤 저장하기를 누릅니다.

파일명2026-10-29_입고확인.xlsx

저장 후에는 홈의 저장된 목록에서 문서를 열 수 있습니다. 문서 안의 사진을 누르면 사진별 결과가 다시 나옵니다.

문서 상세의 ＋ 사진 추가로 같은 작업에 사진을 더 넣을 수 있어요.

6

담당자에게 결과를 보낼 때

파일을 저장하거나 공유하세요

저장된 문서를 열고 아래 버튼을 이용하세요.

↓ 저장

엑셀 또는 CSV 파일을 기기에 내려받습니다.

공유

파일을 만드는 동안 기다리세요. 문서 파일 공유 창이 열리면 파일 공유를 직접 누르고, 보낼 앱과 받는 사람을 고릅니다.

파일 공유가 비활성화되거나 공유 창이 열리지 않으면 같은 창의 파일 저장을 누르세요. 내려받은 파일을 메신저나 메일에 첨부해 보내면 됩니다.

다른 사람에게 전달하려면 파일로 내보내세요

웹주소를 보내는 것만으로 저장된 작업이 전달되지는 않습니다. 작업 기록은 사용한 기기와 브라우저에 저장됩니다. 중요한 결과는 파일로 내보내고, 원본 사진도 사진첩에 따로 보관하세요.

막히는 부분이 있나요?

자주 묻는 질문

아무것도 인식되지 않아요

결과 화면에서 다시 인식을 눌러 보세요. 사진이 흐리거나 바코드가 작게 찍혔다면 더 가까이서 다시 촬영하세요. 원래 코드 개수와 사진의 읽음 개수를 비교해 누락 여부를 확인해 주세요.

카메라가 열리지 않아요

사진 불러오기는 카메라 없이도 사용할 수 있습니다. 촬영하려면 브라우저에서 이 웹사이트의 카메라 사용을 허용해야 합니다. 이미 거부했다면 브라우저의 해당 사이트 권한에서 허용한 뒤 웹앱을 다시 열어 주세요.

웹에서도 바코드가 공간에 고정되나요?

웹 버전은 카메라 화면의 표시와 사진별 결과를 제공합니다. 휴대폰을 움직여도 물리적 위치에 고정되는 AR 공간 추적은 제공하지 않습니다. 최종 결과는 촬영한 사진에서 확인해 주세요.

다른 휴대폰에서 저장된 작업이 안 보여요

작업은 현재 브라우저에 저장됩니다. 다른 기기로 자동 동기화되지 않습니다. 이전 기기에서 결과를 파일로 내보내 전달해 주세요.

저장한 파일이 어디 있는지 모르겠어요

휴대폰의 파일 앱 또는 브라우저의 다운로드 목록을 확인하세요. 문서를 작업 목록에 저장하는 것과 파일을 다운로드하는 것은 별도입니다. 외부 파일이 필요하면 문서 상세에서 ↓ 저장을 누르세요.

사용한 브라우저의 데이터를 지워도 되나요?

브라우저 데이터를 지우면 저장된 문서와 사진 기록도 사라질 수 있습니다. 중요한 결과를 먼저 파일로 내보내고 원본 사진을 따로 보관해 주세요.
